シェーダーは毎フレーム、横 resolution.x = サンプルレート ÷ フレームレート、縦 resolution.y = 行数 の画像を描きます。1ピクセルは「1サンプル × 1本のサイン波」です。各行は自分の周波数で回り続けるサイン波で、R がその瞬間の振幅、G がそこに足す位相（1.0 で1周）です。フレームを横に並べたものが、そのまま1本のスペクトログラムになります。

表示が「楽譜」のときは、書き換えるたびにページ全体（1周分）を先に描いて音を作り、バーがそれを読んでループ再生します。つなぎ目は 20ms のクロスフェードでつなぎます。「流れる（ライブ）」では、鳴らしながら描き続けます。

out[n] = Σ行 R(n, 行) · sin(2π · (hz行 · n / sampleRate + G(n, 行)))

ピクセルごとの入力

t
このピクセルの時刻（秒）。楽譜表示ではページの頭が 0
pos
このピクセルが画面のどこに描かれるか（0〜1）。絵を描くときはこれを座標にすると楽
tl
フレーム先頭からの秒（フレーム内なので精度が高い）
bt
このピクセルの拍。64拍で0に戻るかわりに精度が落ちない。fract(bt) で拍頭からの位置
hz
この行の周波数（Hz）
row
行番号（0 が一番下）
uv
gl_FragCoord.xy / resolution

縦軸の設定

関数

tone(f, amp)
周波数 f のサイン波を、その高さの行に置く（vec2 を返す）。行と行の間でも位相で補正するので音程は正確
sweep(f, cycles, amp)
周波数が動く音。cycles にはその音の位相の積分（何周したか）を渡す
phase(f)
時刻 t での周波数 f の位相（周）。f * t と同じ値を、時間が経っても精度を落とさずに出す。sin(TAU * phase(f)) で正確な LFO・変調波になる
rg(sum)
tone / sweep を足した vec2 を、R = 振幅・G = 位相の vec4 にする
midiHz(n) / hzMidi(f)
MIDI ノート番号と Hz の変換
rowHz(y) / hzY(f)
gl_FragCoord.y と Hz の変換
rowPhase()
このピクセルでのこの行のサイン波の位相（周）
hash(x) / hash(vec2)
0〜1 の乱数
TAU
2π

KodeLife 風に uniform float time; や out vec4 fragColor; を書いても、こちらで重複を取り除くのでそのまま通ります。GPU の float は32bitなので、t そのものから位相を作る（sin(TAU * f * t) など）と、数十秒でノイズが混ざり始めます。音の位相に関わる計算は phase(f) や bt、イベント頭からの経過時間を使ってください。tone と phase は1時間ほどまで精度を保ちます。
